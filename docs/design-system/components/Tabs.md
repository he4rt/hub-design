# Tabs

Duas formas. **Segmentada** (`surface-2`, tab ativa em `surface` com `shadow-tab`) para filtros de lista. **Em linha** (sublinhado 2px `brand` sob a tab ativa, borda `border` abaixo) para seções de uma entidade, como as abas de Meu squad. Contagens vão no texto da tab com ponto médio (`Entregas · 2`), não em pílula.
