# Card

Superfície padrão: `surface`, borda `border`, raio `radius-lg`, padding `space-5`, gap interno 14px. Sem sombra. O cabeçalho é `subheading` à esquerda e, opcionalmente, um chip ou botão `ghost` pequeno à direita.

Variante de resumo (stat): rótulo `caption` em `text-muted`, número em `stat`, legenda `caption`. Ícone de 18px em `brand` no canto.

Bloco `inset` (`surface-2`, raio `radius-md`) para contexto que vem de fora do Hub: o PR, o item do board, o contexto do capitão. Dentro dele, referências ao GitHub em `mono`.
