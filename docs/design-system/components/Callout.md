# Callout

Nota de regra do produto, em `caption`+ (13px) com ícone 16px. Duas variantes: `brand-soft` para regras que protegem o membro (uma candidatura por projeto, publicar só com perfil ligado) e `warning` para consequências irreversíveis (validação imutável, moderação antes de salvar). Sem borda esquerda; o fundo tingido basta.

Banner em `ink`: um só por tela, para o marco que muda o que o membro pode fazer (teste de entrada aprovado). Quadrado `nav-active` com ícone 22px, título `heading` 16px, meta em `on-ink-muted` com referências em `mono`.
