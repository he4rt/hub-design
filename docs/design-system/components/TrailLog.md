# TrailLog

O motivo visual do Hub: uma trilha vertical de pontos ligados, usada no log do squad, no histórico do membro, nos passos do teste de entrada e no "o que acontece ao aceitar". A linha é `border` (2px); o ponto (10px) toma a cor da família do evento: `success-text` para aceito/aprovado, `brand-bright` para movimento (entrou, iniciou), `warning-text` para devolvido, `text-faint` para passado/concluído sem destaque.

Título em `body` 500, meta em `caption` `text-muted` com autor e tempo. O log nunca apaga: entradas devolvidas e encerradas continuam na trilha.
