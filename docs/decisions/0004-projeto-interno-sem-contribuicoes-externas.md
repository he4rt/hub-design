# ADR-0004: Projeto interno, sem contribuições externas

**Status:** Accepted
**Date:** 2026-11-25
**Deciders:** he4rt-devs

## Contexto

O repositório é público, mas não tem licença, `CONTRIBUTING.md`, issues, templates nem CI, e todo
commit precisa dos co-autores Dandan e 7K. Quem chega pelo GitHub não sabe se pode contribuir.

## Decisão

**Por enquanto o hub-design é um projeto interno e não recebe contribuições externas.**

## Consequências

- Não há fluxo de PR, licença nem guia de contribuição para pessoas de fora, e por ora eles não são
  necessários.
- Quando o projeto abrir para fora, um ADR novo define a licença, o fluxo de revisão e como fica a
  regra dos co-autores.
